# The Barcode Story — Motion Graphics Video Essay

An editorial, documentary-level Remotion motion graphics project detailing the 25-year invention saga of the barcode.

## Visual Direction
- **Style**: High-retention documentary motion graphics (editorial, tactile, kinetic).
- **Format**: 1080p (1920x1080) @ 30fps.
- **Palette**:
  - Ink Black: `#0b0d12` (Void canvas)
  - Bone White: `#f2efe6` (Type & lines)
  - Warm Sand: `#c9a66b` (1949 Florida origin)
  - Amber Gold: `#f5b84a` (Juicy Fruit & discovery spark)
  - Cold Blue: `#5b8def` (IBM & tech chasm)
  - Signal Red: `#ff4d3d` (Laser beams & errors)
- **Typography**: Fraunces (Headlines & story beats), JetBrains Mono (Dates, coordinates, code), Inter (Subtitles).

## Quickstart & Rendering

### 1. Interactive Preview (Remotion Player)
```bash
npm install
npm run start
```

### 2. One-Click Render Segment 01
From bash / terminal:
```bash
cd segment_1
./render.sh
```
Or on Windows:
```cmd
cd segment_1
render.bat
```
Output will be written to `render_videos/barcode_revolution/out/segment_1.mp4`.
