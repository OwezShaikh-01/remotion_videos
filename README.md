# Remotion Motion Graphics Showcase

Collection of programmatic motion graphics videos and commercials crafted with [Remotion](https://www.remotion.dev) and React.

---

## 🚀 Featured Project: `AI_AD`

A high-end, 30-second kinetic typography commercial: **"Hire Your Next Lead Motion Designer: AI"**.

- **Aesthetic:** Swiss Modernist & Editorial Graphic Design (Pentagram / Studio Dumbar / Buck style).
- **Techniques:** Character-level 3D kinetic typography, anticipation springs, squash & stretch, impact shockwaves, live cubic-bezier velocity editor, and organic SVG morphing.
- **Duration:** 30 seconds (`900 frames @ 30 FPS`, 1080p Full HD).

### ⚡ 1-Click Quickstart

```bash
# Clone the repository
git clone https://github.com/OwezShaikh-01/remotion_videos.git
cd remotion_videos/AI_AD

# Install dependencies
npm install

# Start Remotion Studio (interactive timeline preview)
npm run dev
```

### 🎬 Render to MP4

```bash
npm run render
```

Finished output is generated at:
```
AI_AD/out/hire-ai-motion.mp4
```

See [`AI_AD/README.md`](AI_AD/README.md) for full scene breakdowns, architecture, and design tokens.
